# Credit Risk Analysis

Proyek analisis risiko gagal bayar pinjaman menggunakan Kaggle Credit Risk Dataset.

## Pertanyaan Bisnis
1. Berapa persentase gagal bayar pinjaman secara keseluruhan dan per loan grade?
2. Tujuan pinjaman (*loan intent*) mana yang memiliki risiko gagal bayar paling tinggi?
3. Apakah status kepemilikan rumah (*home ownership*) berkorelasi dengan tingkat gagal bayar?
4. Bagaimana korelasi antara rasio cicilan terhadap pendapatan (*loan percent income*) dengan risiko gagal bayar?
5. Apakah riwayat gagal bayar sebelumnya (*default on file*) memprediksi potensi gagal bayar saat ini?
6. Kelompok pendapatan (*income band*) dan kelompok umur (*age group*) mana yang paling berisiko?
